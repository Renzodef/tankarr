# Listing Tankarr

Where Tankarr can be listed so that people looking for a "Sonarr for manga"
find it, with the entry each list expects. Submissions are made by a person,
under their own account; some lists refuse automated ones.

| List | Entry | When |
| --- | --- | --- |
| [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted-data) | [`awesome-selfhosted.yml`](awesome-selfhosted.yml) as `software/tankarr.yml` | Once the project has been public for more than four months (their rule), so not before the end of January 2027. Read their `CONTRIBUTING.md` first; the description must stay under 250 characters and must not say "free" or "open source". |
| [awesome-arr](https://github.com/Ravencentric/awesome-arr) | `- [Tankarr](https://github.com/Renzodef/tankarr) - Manga, manhwa and comics manager: Sonarr for manga, with Prowlarr, qBittorrent and SABnzbd.` under **Beyond *arr**, after SoulSync (the list is alphabetical). GitHub's **Edit this file** on their README forks the repository and opens the pull request in one step. | Any time. |
| [Unraid Community Applications](https://forums.unraid.net/topic/87144-ca-application-policies-notes/) | The template in [`../unraid/tankarr.xml`](../unraid/tankarr.xml) | Any time, through the CA forum thread for new applications. |
| [selfh.st](https://selfh.st/apps/) and [Awesome-Selfhosted's](https://awesome-selfhosted.net) mirrors | Follow from the lists above | After the listings above. |

Before submitting anywhere: a release tag exists, the README shows the
screenshots, the documentation site is up, and `docker compose up` on a clean
host works with the `docker-compose.yml` in the repository.
